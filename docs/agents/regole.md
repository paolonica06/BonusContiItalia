# Regole non negoziabili

1. **Solo servizi gratuiti.** Nessun costo senza autorizzazione esplicita di Paolo.
2. **Nessun segreto** nei file, nei commit o in chat: solo GitHub Secrets e variabili d'ambiente Vercel.
   Non leggere `.env*`. Se un segreto compare in chat, non ripeterlo e proporre la rotazione.
3. **Niente spam.** Nessun messaggio automatico in gruppi o chat altrui; l'invio Telegram va solo ai canali di Paolo.
4. **I codici invito non si copiano mai** in resoconti, issue, commit message o log: si citano come
   «il codice BBVA». Vivono solo in `data/offers.json`. Gli script non li stampano.
5. **Non inventare cifre dei bonus.** Fonte: regolamento ufficiale, con data di verifica
   (`last_verified_at`) in `data/offers.json`. Nel dubbio, non pubblicare la cifra.
6. **Dicitura referral obbligatoria** accanto a ogni link invito (ad esempio «codice invito / link
   referral: Paolo riceve un compenso se lo usi»).
7. **Rispetto dei termini dei programmi referral**: niente brand bidding, niente multi-account, niente promesse non previste.
8. **Niente pubblicità** sulle pagine principali.
9. **Niente testi o comportamenti visibili non approvati** (`ui-ux-workflow.md`).
10. **Verifiche prima del push**: `main` va in produzione.
